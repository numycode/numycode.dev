This is my fun little personal site! I have some of my thoughts (a blog with lower standards), some buttons, and a list of other sites I have made! It also has a guestbook from atabook, tons of 88x31s, 2 webrings, and an old-web style.
## Host it yourself
If you really want to, it is just a static site. Just open index.html or use any old website host. I have it set up for Cloudflare Pages.
